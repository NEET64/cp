# Contest Layout 🏆

**By Neet, for Neet, of Neet** — true democracy of competitive programming!

Opens `A.java`, `input.txt`, `output.txt` in a convenient layout and runs your Java, C++ or Python files like a boss.

**Layout:**

- Top: A.java (or any file you're working on)
- Bottom-left: input.txt
- Bottom-right: output.txt

## Usage

1. Open a contest folder in VS Code
2. Press `Ctrl+Shift+P` → **Neet: Set Contest Layout**
3. Watch the magic happen! ✨
4. Use **Neet: Run Java, C++, or Python File** to compile and run your code.

That's it! Now stop reading and go solve some problems! 🚀
